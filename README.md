# Low-Metallicity Binaries in _Gaia_ DR3

This repository is a companion to the publication "A Spectroscopic Search for Dormant Black Holes in Low-Metallicity Binaries" (<a href="https://arxiv.org/abs/2507.12532">Nagarajan et al. 2025</a>). The FEROS and APF spectra analyzed in that work can be found <a href="https://doi.org/10.5281/zenodo.16888415">here</a>. The follow-up MIKE spectrum of the promising dormant black hole candidate described in that work is included here. The repository includes a tutorial notebook demonstrating how to read in all of these spectra.
